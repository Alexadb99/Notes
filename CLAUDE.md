# Rules for this project

The owner's GitHub account was suspended once. Keep everything in this
project inside GitHub's Terms of Service and Acceptable Use Policies.
If a request might break a rule below, stop and tell the owner first.

## GitHub rules to follow
- One personal account only. Never create extra or throwaway accounts.
- No automated bulk activity: no mass starring, following, forking, issues,
  pull requests or comments, and no scripts that hammer GitHub. Normal
  commits and pushes for real work are fine.
- No spam, fake activity or attempts to game stars, followers or stats.
- Only upload content we have the right to share: our own code and writing,
  or open-licensed material with its license kept. No copied apps, art,
  music, fonts or brand logos (for example, no real gym or app branding).
- Never commit secrets: passwords, API keys, tokens, private keys,
  or anyone's personal information. The repo is public.
- No malware, hacking tools aimed at others, or phishing pages.
- No harassment, hate, or content about private individuals.
- No impersonating people, companies or GitHub.
- Use GitHub for code and notes, not as free storage for large files,
  videos or unrelated downloads. Keep files small.
- No crypto mining or heavy compute in GitHub Actions.

## Before every commit
- Check the changes for secrets and personal info.
- Check that anything new is original or properly licensed.
- Keep commit messages honest and plain.

## Notes
